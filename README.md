# Supermarket Billing System

## Overview

A desktop-based Supermarket Billing System developed using Java Swing. The application provides point-of-sale functionality and manages sellers, product categories, products, and store inventory.

## Features

- Admin can add and manage sellers, categories, and products.
- Sellers can add products to the cart according to customer requests.
- Generate bills in PDF format.
- Maintain database records for sellers, categories, and products.
- Manage supermarket inventory through a graphical user interface.

## Technologies Used

- Java
- Java Swing
- JDBC
- Apache NetBeans
- Apache Derby (database)

## Prerequisites

Install the following software to run the application:

- **JDK:** Java Development Kit
- **Apache NetBeans:** IDE for opening and running the project
- **Apache Derby:** Database, if required by the existing project configuration

## How to Run

1. Download or clone this repository.
2. Open Apache NetBeans.
3. Select **File → Open Project**.
4. Select the downloaded project folder.
5. Configure the database connection if necessary.
6. Build and run the project.

Alternatively, if the packaged application and its dependencies are available, open a terminal in the `dist` directory and run:

```bash
java -jar supermarket.jar
```
